# Kumanda

Telefonu bilgisayar için klavye, touchpad ve sesli yazma aracına çevirir (Windows, aynı Wi-Fi).

## Kullanım
1. Releases bölümünden `Kumanda.zip` indir, bir klasöre çıkar.
2. `Kumanda.exe`'ye çift tıkla.
3. Ekranda çıkan adresi telefonda aç (ilk seferde tarayıcı uyarısında "Gelişmiş > Devam et").
4. Telefonda tarayıcı menüsünden "Ana ekrana ekle" yap.

## Güncelleme
`app/` klasöründeki dosyaları GitHub'da değiştirip kaydetmen yeter.
Exe her açılışta en son `app/` dosyalarını indirir. Yeniden derleme gerekmez.
Yalnızca `launcher.py` değişirse yeni etiket (`v1.1`) aç.
